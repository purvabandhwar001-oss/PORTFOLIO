# Purva Bandhwar — Portfolio

React + TypeScript + GSAP (Marginalia template). Everything you'll ever edit is in **`src/content.ts`**.

## Put it online (GitHub Pages)
1. github.com → **New repository** (Public) → upload all these files (keep the `.github` folder).
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. Push/commit to `main`; after ~1 minute the site is at `https://<username>.github.io/<repo>/`.

## Editing
You own the repo, so you have full edit rights. Edit `src/content.ts` directly on github.com (pencil icon → Commit) and the site rebuilds itself.
To add collaborators: Settings → Collaborators.

## Links
Fill the `LINKS` block at the top of `src/content.ts`. Empty links are hidden. Google Drive folders must be shared as "Anyone with the link → Viewer" or visitors will be blocked.

## Photo
Add `public/portrait.jpg` and set `PORTRAIT = BASE + "portrait.jpg"`.

## Run locally
`npm install && npm run dev`
